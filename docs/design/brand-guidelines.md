# BullsNote 디자인 지침 (Brand & UI Guidelines)

> 2026-11-20 확정. 앱 아이콘 A안 **"과녁 체크(Bull's-eye Check)"** 를 기준으로 한 시각 언어.
> 새 화면·컴포넌트·마케팅 이미지를 만들 때 이 문서를 먼저 확인합니다.

## 1. 컨셉

- **이름과 형태의 연결:** Bulls → Bull's-eye(과녁). 과녁 한가운데의 체크는 "할 일을 정확히 끝낸다"는 뜻입니다.
- **제품 성격:** 노트와 할 일이 하나로 묶인 데스크톱 우선, 로컬 퍼스트 앱입니다. 화면은 차분하고, 강조는 완료와 집중의 순간에만 씁니다.
- **지향 감성:** Linear, Notion, Raycast처럼 절제된 미니멀. 장식보다 여백과 위계로 정돈합니다.

## 2. 컬러 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `brand.ink` | `#1F2430` | 아이콘 타일, 다크 표면, 스플래시 배경 |
| `brand.ring` | `#3A4152` | 보조 윤곽, 다크 모드 구분선, 비활성 링 |
| `brand.coral` | `#E2563B` | 브랜드 포인트: 완료 체크, 오늘·집중 강조, 로고 |
| `brand.paper` | `#FFFFFF` | 아이콘 위 체크, 다크 표면 위 전경 |
| UI primary | Mantine `blue` (`#228be6`) | 일반 인터랙션: 링크, 선택, 포커스, 기본 버튼 |

규칙
- **포인트 컬러는 한 화면에 하나만** 씁니다. 코랄은 "완료/집중/브랜드" 의미일 때만 쓰고, 일반 버튼에는 쓰지 않습니다.
- 경고·삭제의 빨강(Mantine `red`)과 브랜드 코랄을 한 영역에 나란히 두지 않습니다.
- 그 외 UI는 무채색(Mantine `gray`, 또는 다크 모드의 `ink` 계열)으로 둡니다.

## 3. 형태 언어

- **동심원 + 체크**가 기본 모티프입니다. 진행률 링, 완료 애니메이션, 빈 상태 일러스트, 로딩 표시에 다시 활용합니다. 예: 할 일 완료 시 코랄 링이 채워지고 체크가 그려지는 효과.
- 선 굵기는 일정하게 하고 끝은 둥글게(`stroke-linecap: round`) 처리합니다. 그라데이션, 그림자, 광택은 쓰지 않습니다.
- 모서리: 앱 아이콘은 타일의 22.5%(`rx 27/120`), UI는 Mantine `defaultRadius: 'md'`를 씁니다.
- UI 아이콘은 `@tabler/icons-react`의 outline 스타일로 통일합니다(굵기 1.5~2).

## 4. UI 원칙

1. **선보다 면:** 패널 구분은 테두리 대신 배경 음영(surface depth)과 여백으로 합니다.
2. **위계는 크기와 굵기로:** 색으로 위계를 만들지 않습니다. 굵기는 400과 500~600 두 단계만 씁니다.
3. **시스템 폰트 스택:** `App.tsx` 테마의 폰트 스택을 그대로 씁니다(SF Pro / Segoe UI Variable / Pretendard).
4. **데스크톱 우선 밀도:** 정보 밀도는 높게 하되, 툴바처럼 맥락에 따라 필요한 요소는 hover나 선택 시에만 드러냅니다.
5. **라이트/다크 동등 지원:** 모든 색은 두 모드에서 대비를 확인합니다. 다크 모드의 기준 표면은 `brand.ink`입니다.
6. **Mantine 유지:** 새 UI 라이브러리를 도입하지 않고 테마 토큰과 컴포넌트 조합으로 해결합니다.

## 5. 아이콘 에셋 파이프라인

- 마스터 파일: `brand/icon.svg`(앱 아이콘), `brand/tray.svg`(단색 트레이 글리프)
- 재생성: `npm run icons` → `scripts/build-icons.cjs`가 Electron(Chromium)으로 래스터화합니다.
  - `electron/assets/icon.icns`(mac, 824/1024 그리드), `icon.png`, `icon.ico`(16~256)
  - `electron/assets/tray-icon(@2x).png`(macOS 템플릿 이미지), `tray-icon-win.png`
  - `public/icon.png`, `icon-192.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon.svg`
- 아이콘은 PNG를 직접 수정하지 않고 **SVG 마스터를 고친 뒤 재생성**합니다.
- 16px에서 형태가 알아볼 수 있는지 반드시 확인합니다. 트레이는 단색 글리프만 씁니다.

## 6. 하지 말 것

- 여러 원색을 한 아이콘·화면에 섞기(이전 아이콘의 빨강·파랑·보라 조합)
- 종이, 연필 같은 사실적이거나 스큐어모픽한 표현
- 코랄을 일반 CTA나 경고색으로 쓰기
- 그라데이션, 네온, 강한 그림자
