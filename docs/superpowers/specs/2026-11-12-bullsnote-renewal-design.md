# BullsNote 리뉴얼 설계 — 컨셉 B "노트와 할일, 두 기둥 + 연결"

- 작성일: 2026-11-12
- 상태: 검토 대기
- 범위: 데스크톱 우선, 배포용 제품 관점의 화면·흐름 개편 (데이터 구조는 유지)

---

## 1. 목적과 전제

### 사용자가 정한 것
- BullsNote를 **다른 사람에게도 배포하는 제품**으로 만든다.
- 중심은 **노트와 할일**이다. **일정(플래너)은 할일을 시각적으로 확인하기 위한 보기**다.
- 새 사용자는 **로그인 없이 바로 시작**하고, 동기화는 원할 때 **"Google로 계속" 버튼 하나**로 켠다.
- 주 사용 환경은 **데스크톱**이고, 모바일(PWA)은 보조다.
- AI 기능은 유지하되, **MCP 할일 도구 등 AI 확장은 이번 범위에서 제외하고 후속 과제로 기록**한다 (8장).

### 가정 (검토 시 확인 필요)
- 데이터는 계속 사용자 기기와 사용자 본인의 Google Drive에만 둔다. 별도 서버는 만들지 않는다.
- 기존 기능은 삭제하지 않고 **위치와 노출 방식**을 재배치한다.
- 할일 데이터 모델(할일 프로젝트 `TODO_PROJECT_ID` 안의 노트 + 상태·시작일·마감일·소요일)은 그대로 둔다.
- UI 라이브러리는 Mantine을 유지한다. `ui.md`의 Tailwind·shadcn 전면 교체는 하지 않는다.

### 성공 기준
- 처음 설치한 사용자가 **설정 없이 1분 안에 첫 노트와 첫 할일을 만든다.**
- 앱을 열면 **"오늘" 화면 하나로 오늘 할 일·알림 일정·진행 중 작업**을 파악한다.
- 할일관리와 플래너가 **하나의 "할일" 화면**(목록 / 보드 / 타임라인)으로 합쳐진다.
- 노트의 체크리스트 항목을 **한 번의 클릭으로 할일과 연결**하고, 완료 상태가 양쪽에서 일치한다.

## 2. 정보 구조 (사이드바)

```
[+ 빠른 입력  ⌘N]
[검색        ⌘K]

오늘            ← 대시보드
할일            ← 목록 / 보드 / 타임라인 + 필터

노트
  즐겨찾기
  폴더 트리 (최대 3단계, 기존 유지)
  태그

──────────────
이 기기에 저장됨 · 동기화   ← 동기화 상태/진입점
설정
```

- 기존 사이드바의 "할일관리"·"플래너" 항목은 없어지고 **"할일" 하나**로 합쳐진다.
- 사이드바 하단 **미니 달력은 제거**한다. 날짜 탐색은 "할일" 화면의 타임라인과 기간 필터가 맡는다.
- "예정 / 미분류 / 전체" 같은 기준이 모호한 메뉴는 두지 않는다. 대신 "할일" 화면의 필터로 처리한다 (3.2).

## 3. 화면 설계

### 3.1 오늘 (대시보드)

헤더: `11월 12일 목요일 · 할 일 N · 진행 중 N · 지연 N`

| 영역 | 포함 기준 | 표시 |
|---|---|---|
| 오늘 할 일 (왼쪽, 넓게) | 마감일 = 오늘, 마감일 < 오늘이고 미완료(지연), 상태 = 진행 중 | 카드: 제목, 상태, 마감 표시, **본문 첫 줄 미리보기**, 본문 체크리스트 진행률(예: 1/3), 출처 노트 링크. 지연 항목이 맨 위 |
| 오늘 일정 (오른쪽 위) | 오늘 시각에 알림이 걸린 할일·노트 (`reminder.targetAt`, 마감일 09:00 자동 알림 포함) | 시간 축 타임라인, 현재 시각 선 |
| 진행 중인 기간 작업 (오른쪽 아래) | 시작일 ≤ 오늘 ≤ 마감일 | 제목, D-day, 경과 기간 막대 |

- 카드 클릭 시 오른쪽 상세 패널(3.3)을 연다.
- **제약:** 할일에는 마감 "날짜"만 있고 "시각" 필드가 없다. 시각이 없는 할일은 "오늘 일정"에 나오지 않는다 (후속 과제 8장).

### 3.2 할일

- 상단 오른쪽에 보기 전환: **목록 / 보드 / 타임라인**
  - 목록: 기존 할일관리 목록 + 내용 미리보기
  - 보드: 상태별 열 (대기 / 진행 중 / 완료 / 중단)
  - 타임라인: 기존 간트 플래너 (`PlannerView`) 이전
- 필터 (각 필터는 한 가지 기준만 가진다)

| 필터 | 값 |
|---|---|
| 상태 | 대기 / 진행 중 / 완료 / 중단 |
| 기간 | 지연 / 이번 주 / 날짜 없음 |
| 분류 | 폴더, 태그 |

- 상단에 인라인 "할일 추가" 입력줄 (빠른 입력과 같은 파서 사용).
- 보기·필터 상태는 기존 플래너처럼 로컬에 기억한다.

### 3.3 상세 패널

- 할일을 선택하면 화면 전환 없이 **오른쪽 패널**로 열린다.
- 내용: 제목, 상태, 기간(시작일·마감일·소요일, 근무일 계산 유지), 알림, 태그, 출처 노트 링크, **본문(기존 블록 에디터)**.
- 모바일에서는 이미 구현한 전체 화면 노트 상세(`MobileNoteHeader`)를 그대로 쓴다.

### 3.4 노트

- 기존 노트 목록·에디터 유지.
- 체크리스트 항목에 **"+ 할일로"** 버튼과 연결 배지(`할일 · 11/13`, `완료`)를 표시 (4.2).

## 4. 입력 흐름

### 4.1 빠른 입력 (⌘N)

- 어떤 화면에서든 같은 입력 창을 연다. 상단 토글: **할일 / 노트** (Tab으로 전환).
- 한 줄 입력에서 날짜·시각·`#태그`를 인식해 칩으로 표시한다. 칩은 눌러서 수정·삭제할 수 있다.
  - 예: `내일 3시 견적서 회신 #업무` → 마감 11/13, 알림 15:00, 폴더/태그 업무
  - 날짜 인식은 기존 `dateSuggestions`의 `@오늘`·`@내일` 로직을 재사용·확장한다.
- 기본값: 날짜가 있으면 할일, 없으면 노트.
- `Enter` 저장 후 닫기, `⇧Enter` 본문 입력 영역 펼치기.
- 긴 텍스트를 붙여넣으면 **"AI로 정리"** 버튼 표시 (5장, AI가 켜진 경우만).
- 이번 범위는 **앱 안 단축키**까지. OS 전역 단축키는 후속 과제.

### 4.2 노트 체크리스트 → 할일

- 체크리스트 항목마다 "+ 할일로" → 해당 항목 하나를 할일로 연결 (현재 `createTodosFromChecklist`는 일괄 등록이므로 단일 항목 연결을 추가).
- 연결된 항목에는 배지 표시, 클릭 시 상세 패널.
- 완료 상태 양방향 동기화는 기존 로직 유지.
- 할일 쪽에는 출처 노트 링크(`← 주간 회의록 11/10`)를 표시.

## 5. AI 기능 배치

### 유지
- 에디터 AI 작업 8종 (`AI_ACTIONS_META`): 3줄 요약, 서식 정리, 맞춤법 교정, 할 일 추출, 이어 쓰기, 영어/한국어 번역, 자유 요청 — 노트의 `/` 메뉴와 서식 막대에 그대로 둔다.
- 내장 MCP 서버(`save_note`, `list_projects`)와 Claude Desktop·Gemini CLI 연결 설정 — 설정 화면에 그대로 둔다.

### 변경
1. **"할 일 추출" → 할일 연결의 시작점.** 추출된 체크리스트 항목에 "+ 할일로" 버튼이 붙고, **"모두 할일로"** 일괄 버튼을 추가한다.
2. **헤더의 AI 버튼(클립보드 요약 모달, `GeminiAiModal` clipboard 탭)을 빠른 입력에 통합.** 붙여넣은 긴 글을 "AI로 정리" → 요약 노트로 저장 또는 할 일 추출 후 할일 등록. AI 진입점은 빠른 입력과 노트 안 두 곳으로 줄인다.
3. **AI는 사용자가 켜는 기능(opt-in).** Gemini API 키가 없으면 AI 버튼 대신 "AI 기능 켜기" 안내만 보이고, 키 입력은 설정 > AI 연결로 옮긴다. 키 없이도 나머지 기능은 모두 동작한다.

## 6. 첫 실행과 동기화

### 6.1 첫 실행
- 로그인 화면(`LoginView`) 대신 **환영 화면**: 주 버튼 "바로 시작하기", 보조 버튼 "다른 기기에서 쓰던 데이터 불러오기".
- 바로 시작 시 로컬 저장으로 시작 (현재 게스트/오프라인 모드를 기본 경로로 승격).
- 예시 노트 1개 + 예시 할일 3개를 생성해 "오늘" 화면이 비어 있지 않게 한다.

### 6.2 동기화 켜기
- 진입점: 사이드바 하단 "이 기기에 저장됨 · 동기화".
- 안내 3줄(저장 위치: 내 Drive의 BullsNote 폴더 / 휴대폰 알림은 Google 캘린더 / 언제든 끌 수 있음) + **"Google로 계속"** 버튼 하나.
- 기존 Client ID·Secret 직접 입력은 **"고급: 내 OAuth 클라이언트 사용"**으로 숨긴다.
- 상태 표시: `이 기기에 저장됨` → `동기화됨 · 1분 전` / `동기화 중` / `오프라인`.
- 기존 로컬 데이터와 Drive 데이터 병합은 현재 동기화 정책(스토리지 데이터 우선, 기본 프로젝트 덮어쓰기 방지)을 따른다.

### 6.3 권한 단계적 요청
- 동기화 최초 연결 시: `drive.file`, `userinfo.email`, `userinfo.profile`만 요청.
- `calendar.events`: 알림의 휴대폰 푸시(캘린더 연동)를 켤 때 추가 요청.
- `tasks`: Google Tasks 연동을 켤 때 추가 요청.
- 이유: 캘린더·Tasks는 Google 앱 심사에서 민감 권한으로 분류되어 심사 기간이 길다. 단계적 요청으로 심사 전에도 기본 동기화를 제공한다.

### 6.4 휴대폰 연결
- 동기화를 켠 사용자에게만 "휴대폰에서도 쓰기" 표시.
- 기존 연결 코드(`BNM1:...`)를 **QR 코드**로도 제공, 코드 복사는 예비 경로로 유지.

## 7. 화면 정돈 원칙 (세부 디자인은 frontend-design 스킬로 별도 진행)

- Mantine 유지, 테마 토큰(색·여백·라운드)만 정리한다.
- 패널 구분은 테두리보다 배경 음영과 여백을 우선한다.
- 한 화면의 강조 버튼(채움색)은 하나만 둔다.
- 영문 병기 라벨(`Task Name (작업명)`, `일별 (Day)` 등)은 한국어 단일 라벨로 정리한다.
- 모바일은 이미 적용한 패턴(`src/view/mobile/`의 상단바·하단 시트·키보드 보조 막대·길게 눌러 드래그)을 재사용한다.

## 8. 범위 밖 — 후속 과제 (잊지 않도록 기록)

### AI 관련 (사용자 요청으로 명시 기록)
1. **MCP 할일 도구 추가:** `add_todo`(제목·마감일·메모), `list_today`(오늘 화면과 같은 기준) 등. Claude Desktop·Gemini CLI에서 말로 할일 등록. 현재 MCP 도구는 `save_note`, `list_projects`뿐 (`electron/mcp/server.js`).
2. **오늘 브리핑:** 오늘 화면에서 할 일·일정·지연 항목을 AI가 요약.
3. **빠른 입력 AI 파싱 보강:** 규칙 기반으로 못 읽는 자연어 날짜·우선순위를 AI로 보조 해석 (AI가 켜진 경우만).

### 기타
4. 할일 **마감 시각 필드** 추가 → "오늘 일정"을 시각 단위로 채우기 (데이터 모델 변경).
5. 데스크톱 **OS 전역 단축키**로 빠른 입력 띄우기.
6. Google OAuth 앱 등록·심사, 개인정보처리방침 페이지, 시연 영상 준비 (배포 선행 조건).

### 구현 순서 제안 (각각 독립 PR)
1. 첫 실행·동기화 흐름 (배포 장벽 제거)
2. 사이드바 재구성 + 할일 화면 통합(목록/보드/타임라인)
3. 오늘 대시보드
4. 빠른 입력 + 체크리스트 단일 연결 + AI 진입점 통합
5. 화면 정돈 (frontend-design)

### 테스트
- 현재 테스트 프레임워크가 없다. 오늘 화면 포함 기준(3.1)·필터 기준(3.2)·빠른 입력 파서(4.1)는 순수 함수로 분리해 단위 테스트를 추가한다 (Vitest 도입 검토).
- 화면은 데스크톱·모바일 뷰포트에서 브라우저로 확인한다.
