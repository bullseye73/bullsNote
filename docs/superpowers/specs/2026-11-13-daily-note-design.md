# Daily Note 되살리기 — 오늘 화면의 하루 계획표

- 작성일: 2026-11-13
- 상태: 검토 대기 (빌더 점검: 작성자 자체 점검)
- 상위 설계: `docs/superpowers/specs/2026-11-12-bullsnote-renewal-design.md` (컨셉 B)
- 브랜치: `feat/renewal-concept-b` 위에서 진행

## 1. 목적

옵시디언의 Daily Note처럼 **하루 기록의 기본 착지점**을 되살린다. 사용자는 Daily Note를 **아침에 오늘 할 일의 순서와 주의점을 미리 정리하는 계획표**로 썼고, 급할 때는 회의 내용도 적었다. 리뉴얼 뒤 Daily Note는 "날짜 이름의 빈 노트를 여는 버튼"만 남아 이 역할을 잃었다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
1. 오늘 화면 안에서 Daily Note를 바로 쓰고 고친다 (계획표 템플릿 + `오늘 순서` 미리 채우기).
2. 오늘 화면에서 날짜를 옮겨(어제·내일·달력) 그날의 할 일·일정·Daily Note를 함께 본다.
3. 빠른 입력에서 "오늘 노트"를 골라 오늘 Daily Note의 `메모` 칸에 한 줄을 덧붙인다.

**비목표 (이번에 하지 않음)**
- 회의록 템플릿으로 바로 작성하기 — 사용자가 나중에 넣기로 함. 이번 템플릿 구조는 그때 재사용할 수 있게 만든다.
- 템플릿 내용 편집 화면, 주간·월간 노트, 반복 일정.
- 모바일 셸에 오늘 화면 넣기 (모바일 "오늘노트" 탭은 기존처럼 노트를 연다. 새 템플릿은 적용된다).

**실패 조건 (동작해도 실패로 본다)**
- 날짜만 둘러봐도 빈 Daily Note가 날짜마다 생긴다.
- 오늘 화면에서 Daily Note를 열거나 만들 때 노트 화면의 선택·폴더가 바뀌거나 커서를 빼앗는다.
- `오늘 순서` 미리 채우기 때문에 같은 할 일이 중복 할일로 생긴다.
- 같은 노트를 두 곳에서 편집하다 내용이 사라진다.

## 3. 제약

- 저장 구조는 기존 그대로: `Daily Note` 폴더 → `YYYY-MM` 월 노트 → `YYYY-MM-DD` 날짜 노트 (`openOrCreateDailyNote`).
- 노트 데이터 모델(`Note`, `TodoMeta`) 변경 금지.
- 날짜 노트 본문은 다른 노트와 같은 BlockNote 블록 JSON.
- 새 UI 라이브러리 금지 (`@mantine/dates` 없음 → 기존 `MiniCalendar` 재사용).

## 4. 검토한 방식

| 안 | 내용 | 장단점 | 결정 |
|---|---|---|---|
| **A. 오늘 화면 안에서 바로 편집** | 오늘 화면에 Daily Note 블록 에디터를 접고 펼 수 있게 넣음 | 할 일을 보며 바로 계획을 적음 / 화면이 길어짐 → 접기로 해결 | **선택 (사용자)** |
| B. 미리보기 + 오른쪽 패널 편집 | 처음 몇 줄만 보이고 누르면 패널 | 화면이 짧음 / 매번 한 번 더 누르고 패널이 할 일을 가림 | 제외 |
| C. 별도 Daily 화면 | 사이드바에 Daily 항목, 날짜별 전체 페이지 | 옵시디언과 가장 비슷 / 오늘 화면과 할 일이 분리되어 리뉴얼 방향과 어긋남 | 제외 |

## 5. 설계

### 5.1 오늘 화면 구성 (A안)

```
‹  11월 13일 금요일  ›  [오늘] [달력]      할 일 3 · 진행 중 1 · 지연 1     [할일 추가]
┌────────────────────────────────────┐ ┌──────────────────────┐
│ ▾ 오늘 노트                    [노트로 열기] │ │ 오늘 일정            │
│  ## 오늘 순서                                │ │ 09:00 ...            │
│  1. 견적서 회신                              │ │ ── 13:40 ──          │
│  2. 분기 보고서 초안                         │ │                      │
│  ## 주의할 점                                │ │ 진행 중인 기간 작업  │
│  -                                           │ │ ...                  │
│  ## 메모                                     │ └──────────────────────┘
│  - 14:30 고객사 통화: 단가 재확인            │
├────────────────────────────────────┤
│ 오늘 할 일 (카드 목록)                       │
└────────────────────────────────────┘
```

- 왼쪽 열 맨 위에 **"오늘 노트" 영역**, 그 아래 "오늘 할 일" 카드. 오른쪽 열은 기존 그대로.
- 영역은 접고 펼 수 있고, 접힘 상태를 기억한다 (localStorage `bullsnote.today.dailyCollapsed`).
- 에디터는 노트 화면과 같은 블록 에디터(`/` 메뉴, 체크리스트, "+ 할일로" 포함). 오늘 화면 안에서는 첨부·백링크 하단 패널을 숨기고, 높이가 길어지면 영역 안에서 스크롤한다(최대 약 화면 높이의 55%).
- "노트로 열기"는 노트 화면에서 그 날짜 노트를 연다 (`openNote`).
- 선택한 날짜의 Daily Note가 **없으면 자동으로 만들지 않는다**. 대신 "이 날의 노트 시작하기" 버튼을 보여주고, 누르면 템플릿으로 만든다. (실패 조건 1 방지)
- 오늘 화면에서 Daily Note를 찾거나 만들 때 노트 화면의 선택·폴더를 바꾸지 않는다. (실패 조건 2 방지 — 기존 `openOrCreateDailyNote`는 선택을 바꾸므로, 선택을 건드리지 않는 `ensureDailyNote`를 분리하고 기존 함수는 그것 + 선택으로 바꾼다)

### 5.2 템플릿

처음 만들 때 넣는 본문:

```
## 오늘 순서
1. (그날 "오늘 할 일" 제목들 — 지연 → 그날 마감 → 진행 중 순)
## 주의할 점
- (빈 항목)
## 메모
(빈 문단)
```

- `오늘 순서`는 만드는 순간의 "오늘 할 일"(`getTodayBoard(그 날짜).tasks`) 제목을 **번호 목록**으로 넣는다. 할 일이 없으면 빈 번호 항목 하나.
- 체크박스가 아닌 번호 목록이므로 "+ 할일로"가 붙지 않아 중복 할일이 생기지 않는다. (실패 조건 3 방지)
- 처음 만들 때 한 번만 채운다. 이후 생긴 할 일은 자동으로 들어가지 않는다.
- 템플릿은 "제목 + 블록 목록을 만드는 함수" 하나로 두어, 나중에 회의록 템플릿을 같은 방식으로 추가할 수 있게 한다.
- 모바일 "오늘노트" 탭, 노트 목록의 날짜 노트 만들기 등 기존 진입점으로 새로 만들 때도 같은 템플릿을 쓴다.

### 5.3 날짜 이동

- 헤더 왼쪽: `‹` 어제, 날짜 제목, `›` 내일. 오늘이 아닐 때만 `[오늘]` 버튼. `[달력]`은 기존 `MiniCalendar`를 값·변경 콜백을 받는 형태로 일반화해 팝오버로 띄운다(Daily Note가 있는 날 표시).
- 날짜를 바꾸면 세 영역이 모두 그 날짜 기준으로 바뀐다:
  - 할 일: `getTodayBoard(선택한 날짜)` — 그 날짜까지 마감인 미완료, 진행 중 할일. 상태는 현재 상태 기준이다(과거 시점의 상태를 복원하지 않음).
  - 일정: 그 날짜의 알림.
  - 진행 중인 기간 작업: 그 날짜를 포함하는 기간.
  - Daily Note: 그 날짜 노트.
- 헤더 문구: 오늘이면 "11월 13일 금요일", 다른 날이면 날짜 + "(어제)", "(내일)", 또는 요일만.
- 자정이 지나 실제 오늘이 바뀌어도, 사용자가 다른 날짜를 보고 있으면 그대로 둔다. 오늘을 보고 있었으면 새 오늘로 따라간다.

### 5.4 빠른 입력 "오늘 노트"

- 토글이 `할일 / 노트 / 오늘 노트` 세 가지가 되고 Tab으로 순환한다.
- "오늘 노트"는 날짜·시각을 해석하지 않고 원문 그대로 저장한다(#태그는 남김).
- 저장 위치: **실제 오늘** 날짜 노트의 `메모` 칸 맨 아래에 글머리 항목 `HH:MM 입력 내용`을 붙인다. `⇧Enter` 메모가 있으면 그 아래 줄로 이어 붙인다.
- 오늘 노트가 없으면 템플릿으로 만든 뒤 붙인다. `메모` 제목이 없으면(사용자가 지웠으면) 본문 맨 끝에 `## 메모`를 추가하고 붙인다.
- 그 노트가 오늘 화면이나 노트 화면에 열려 있으면, 기존 "외부 변경 반영"으로 에디터에 바로 나타난다. (실패 조건 4: 블록 에디터는 변경마다 즉시 `updateContent`로 공용 상태에 반영하므로, 붙이기는 공용 상태의 최신 본문에 대해 함수형 업데이트로 수행한다. 저장되지 않은 입력이 따로 남지 않는다)
- 빠른 입력의 기본 선택은 그대로 (날짜가 있으면 할일, 없으면 노트). "오늘 노트"는 사용자가 고를 때만.

## 7. 빌더에게 맡기는 것

- Daily Note 영역의 정확한 높이·여백, 접기 아이콘.
- 템플릿 제목 수준(H2 권장)과 빈 항목 표현.
- 날짜 노트가 있는 날 달력 표시 방식(점, 굵게 등).

## 8. 내가 정한 것 (사용자 확인 필요)

- 날짜를 둘러볼 때 Daily Note를 자동으로 만들지 않고 "이 날의 노트 시작하기" 버튼으로 만든다.
- 과거 날짜의 할 일은 현재 상태 기준으로 보여준다.
- "오늘 노트"로 붙이는 줄은 `HH:MM 내용` 글머리 항목, 위치는 `메모` 칸 맨 아래.
- 오늘 화면 안 에디터에서는 첨부·백링크 하단 패널을 숨긴다(노트로 열면 보임).
