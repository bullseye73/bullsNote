# AI 보조 3종 설계 (MCP 할일 도구 · 오늘 브리핑 · 빠른 입력 AI 해석)

## 의도
리뉴얼(컨셉 B) 때 미뤄 둔 AI 과제. 노트·할일 두 기둥을 AI가 거들되, 예측 가능하고 비용이 드는 호출은 사용자가 누를 때만 한다.

## 결정 (사용자 승인 2026-11-13)
1. **MCP 할일 도구** (데스크톱 전용, `electron/mcp`)
   - `add_todo { title, dueDate?, time?, memo? }`: 할일관리 To Do 그룹에 새 할일 파일 생성. dueDate는 `YYYY-MM-DD` 또는 오늘/내일/모레. time(`HH:mm`)이 있으면 그 시각 알림, 없고 마감일만 있으면 마감일 09:00 알림(앱 규칙과 동일). 날짜가 없으면 일정 없는 할일.
   - `list_today {}`: 오늘 날짜, 오늘 할 일(지연·오늘 마감·진행 중), 오늘 일정(알림 시각)을 텍스트로 반환. 기준은 `TaskQueryService.getTodayBoard`와 같다(같은 예시로 테스트).
   - 앱 TS 코드를 쓸 수 없어 규칙을 `electron/mcp/todos.js`에 JS로 둔다. 상태는 부모 체인의 시스템 그룹으로, 날짜는 `todoMeta`의 명시 날짜로만 판단(하위 작업 롤업은 제외 — 차이 허용).
2. **오늘 브리핑**: 오늘 화면(오늘 날짜일 때) 위쪽 카드. "브리핑 만들기" 버튼을 눌러야 Gemini 호출. 입력은 오늘 할 일·일정·오늘 노트 본문. 결과 3~4줄을 날짜별로 localStorage에 저장, 다시 만들기 가능. 키 없으면 "AI 켜기".
3. **빠른 입력 AI 해석**: 규칙 해석은 그대로. 키가 있고 할일/노트 종류일 때 ✨ 버튼 → Gemini가 JSON `{title,dueDate,time,tags}` 반환 → 검증(날짜 형식·실존·오늘 이전 불가, 시각 형식) 통과 시 칩을 대체, 실패 시 규칙 결과 유지·안내. 텍스트를 바꾸면 AI 결과 해제.
